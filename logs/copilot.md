# Coding Agent Record

## Selected agent

GitHub Copilot

## Tool class

AI coding agent / AI-assisted software development tool.

## Repository access

GitHub Copilot is used through the development environment (VS Code) and works with files in the local project repository.

## Operations used in this project

The agent can:
- analyze project files and directory structure;
- suggest and generate code;
- modify files in the repository;
- explain and review code;
- help identify errors;
- propose changes based on project context.

## Use in Lab 1

For this laboratory work, GitHub Copilot will be used to:
1. analyze the repository structure;
2. make a controlled change to a project file;
3. allow the student to review the resulting changes using Git;
4. participate in a simulated human-agent conflict resolution scenario.

All changes generated by the agent will be reviewed by the student before being committed.
